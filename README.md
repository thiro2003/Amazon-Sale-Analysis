# 📊 Amazon Sales Analysis  

This project analyzes Amazon sales data using **Power BI** to uncover insights into revenue, product performance, customer behavior, and trends. The dashboard provides interactive visualizations for better decision-making.  

---

## 🚀 Features  
- Interactive **Power BI Dashboard**  
- Sales overview with total revenue, profit, and orders  
- **Category & Sub-category performance** analysis  
- Monthly & yearly **sales trends**  
- **Top-performing products** and underperformers  
- **Geographical insights** into sales distribution  
- Filters for dynamic analysis  

---

## 🛠️ Technologies Used  
- **Power BI** – Data cleaning, modeling, and visualization  
- **Excel / CSV** – Source dataset (Amazon Sales Data)
